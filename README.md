I'm a founder and hands-on engineer. I run two software companies and still write a lot of the code myself.

- 🏢 **CEO of [Treevoxa](https://treevoxa.com)**, a software studio building SaaS products and custom ERP, CRM, HRM and accounting systems

- 💻 Full-stack developer, mobile app architect and technical team lead with **3+ years** of shipping production software
